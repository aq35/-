# 7. エンジニアの仕事で使う言葉（英語・読み方・日本語）

仕事のチャット・レビュー・会議でよく出てくる言葉を、場面別にまとめました。

## 見方

| EN | 英語（略語は展開した英文） |
|:---|:---|
| 読み | カタカナ読み（`／` の前が略語のアルファベット読み、後ろが展開した英文の読み。`(ト)` は弱くなる音） |
| JP | 日本語の意味 |
| 場面 | 実際に使う場面と例 |

> カタカナ読みは目安です。実際の発音は、動画や辞書の音声で確認してください。

## 1. 日々のやりとり（Slack・PR・会議）

チャットやレビューで毎日出てくる略語と言い回し。略語は「アルファベットの読み」と「展開した英文の読み」を併記しています。

#### LGTM

| EN | Looks good to me. |
|:---|:---|
| 読み | エル・ジー・ティー・エム ／ ルックス グッ(ド) トゥ ミー |
| JP | 問題なさそう（レビューの承認） |
| 場面 | PR のレビューで「これで OK です」と返すとき |

#### PTAL

| EN | Please take a look. |
|:---|:---|
| 読み | ピー・ティー・エー・エル ／ プリーズ テイク ア ルック |
| JP | 見てください（確認のお願い） |
| 場面 | レビューや確認を依頼するとき。「PTAL: 修正しました」 |

#### nit

| EN | nitpick（細かい指摘） |
|:---|:---|
| 読み | ニッ(ト) ／ ニッ(ト)ピッ(ク) |
| JP | 細かい指摘（直さなくてもよい） |
| 場面 | 「nit: 変数名は user_id の方が分かりやすいかも」 |

#### WIP

| EN | Work in progress. |
|:---|:---|
| 読み | ダブリュー・アイ・ピー ／ ワーキン プログレス |
| JP | 作業中（まだ完成していない） |
| 場面 | PR タイトルに [WIP] を付ける（Draft PR） |

#### FYI

| EN | For your information. |
|:---|:---|
| 読み | エフ・ワイ・アイ ／ フォーユア インフォメイション |
| JP | ご参考まで（対応不要） |
| 場面 | 対応は要らない情報共有 |

#### ASAP

| EN | As soon as possible. |
|:---|:---|
| 読み | エイサップ ／ アズ スーン アズ ポッスィブル |
| JP | できるだけ早く |
| 場面 | 急ぎの依頼。使いすぎると緊急度が伝わらなくなる |

#### TL;DR

| EN | Too long; didn't read. |
|:---|:---|
| 読み | ティー・エル・ディー・アール ／ トゥー ロング ディドゥン(ト) リード |
| JP | 長いので要約すると |
| 場面 | 長文の冒頭に結論を置く |

#### ETA

| EN | Estimated time of arrival. |
|:---|:---|
| 読み | イー・ティー・エー ／ エスティメイティッ(ド) タイモヴ アライヴァル |
| JP | 完了の見込み時刻 |
| 場面 | 「ETA は明日の午後です」 |

#### EOD

| EN | End of day. |
|:---|:---|
| 読み | イー・オー・ディー ／ エンドヴ デイ |
| JP | 今日の終業まで |
| 場面 | 「EOD までに返事します」 |

#### OOO

| EN | Out of office. |
|:---|:---|
| 読み | オー・オー・オー ／ アウトヴ オフィス |
| JP | 不在 |
| 場面 | 休暇・外出の通知 |

#### TBD

| EN | To be determined. |
|:---|:---|
| 読み | ティー・ビー・ディー ／ トゥ ビー ディターミンド |
| JP | 未定 |
| 場面 | まだ決まっていない項目 |

#### AFAIK

| EN | As far as I know. |
|:---|:---|
| 読み | エー・エフ・エー・アイ・ケー ／ アズ ファー アズ アイ ノウ |
| JP | 私の知る限り |
| 場面 | 断定を避けるとき。「AFAIK、この API は非推奨です」 |

#### IMO

| EN | In my opinion. |
|:---|:---|
| 読み | アイ・エム・オー ／ イン マイ オピニオン |
| JP | 私の意見では |
| 場面 | 意見と事実を分けて伝える |

#### sync

| EN | Let's sync up. |
|:---|:---|
| 読み | シンク ／ レッツ シンカップ |
| JP | 認識をそろえる（短い打ち合わせ） |
| 場面 | 「明日 15 分 sync しましょう」 |

#### action item

| EN | action item |
|:---|:---|
| 読み | アクション アイテム |
| JP | 会議で決まった「やること」 |
| 場面 | 議事録に担当者と期限つきで書く |

#### blocker

| EN | blocker |
|:---|:---|
| 読み | ブロッカー |
| JP | 作業を止めている障害 |
| 場面 | 「スキーマ側の PR が blocker です」 |
