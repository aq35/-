# 英語の学習: 指示文を 1 文ずつ

[09. 私用の AI 指示文](../09-my-ai-prompts.md) の英語版を、英語の勉強として読むためのページです。長くて疲れないように、**指示文ごとにファイルを分けて**います。

## 使い方

1. 日本語の指示文で、何を頼む文かを先に確認する
2. 学習ページで、1 文ずつ「英語 → 読み方 → 日本語訳」を見る
3. 読み方を見ながら、声に出して読む
4. 知らない単語は、ページ末尾のリンクから[単語表](words.md)で確認する

## 読み方の見方

各文は、次の 4 行の表です。

| EN | 英文。`‿` は音がつながる場所（例: `Answer‿in Japanese.`） |
|:---|:---|
| 読み | カタカナ読み。英文と**同じ位置**に `‿` を入れています（例: `アンサ‿リン ジャパニーズ`） |
| つながり | どの単語と単語が、どの型でつながるか（例: `Answer‿in（r＋母音）`） |
| JP | 日本語訳 |

- `(ト)` `(ド)` `(プ)` は、弱くなる音です。はっきり発音しなくてかまいません
- 発音は**アメリカ英語**を基準にしています（`that I` → ザ‿ライ のように、t がラ行に近くなる）
- つながりの型と練習のしかたは、[リンキングの解説](linking.md) にまとめています
